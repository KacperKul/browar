# BROWAR

Otwórz `BROWAR.html` w przeglądarce. Aplikacja nie wymaga instalacji ani serwera.

## Zdjęcia piwa

Dodaj własne zdjęcia do tego samego folderu co `BROWAR.html`, używając dokładnie poniższych nazw (małe litery, rozszerzenie `.png`).

| Wynik | Nazwa pliku |
| --- | --- |
| Piwo bezalkoholowe owocowe | `bezalkoholowe-owocowe.png` |
| Lager bezalkoholowy | `lager-bezalkoholowy.png` |
| Stout | `stout.png` |
| Porter | `porter.png` |
| IPA | `ipa.png` |
| Pils | `pils.png` |
| Piwo pszeniczne (Weizen) | `weizen.png` |
| Jasny lager | `lager.png` |

Każdy wynik ma białą ramkę o wysokości 240 px i szerokości dopasowanej do karty. Zdjęcia zachowują proporcje i mieszczą się w całości, bez przycinania i rozciągania. Najlepiej sprawdzą się zdjęcia na białym tle, z podobnym marginesem wokół piwa. Przed dodaniem zdjęcia lub gdy plik się nie wczyta, w ramce wyświetla się ikona butelki.
